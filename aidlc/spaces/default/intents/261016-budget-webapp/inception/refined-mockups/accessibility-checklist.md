# アクセシビリティ確認リスト

- 目標: requirements.md NFR2（WCAG 2.1 AA の主要項目）と FR9（キーボード操作）。対象ペルソナは P2（キーボードだけで操作する利用者）を含む全利用者。

## 2. キーボード操作のシナリオ（AC9.1.1 の分解）

| # | シナリオ | 使うキー | 期待する結果 |
|---|----------|----------|--------------|
| K1 | 収支を1件登録する | Tab、矢印（種別）、文字入力、Enter | 一覧に追加され、フォーカスは金額欄 |
| K2 | 収支を編集する | Tab、Enter、文字入力、Enter | 値が変わり、フォーカスは押した「編集」 |
| K3 | 収支を削除する（キャンセル→確定） | Tab、Enter、Esc、Tab、Enter | Esc では消えず「削除」に戻る。確定で消える |
| K4 | タブを切り替える | 矢印（左右）、Home、End、Tab | 選択と内容が切り替わる |
| K5 | 月を移動する | Tab、Enter | 前月・翌月に切り替わり、読み上げで月が分かる |
| K6 | 予算を設定・解除する | Tab、文字入力、Enter、Tab、Enter | 設定済み→引き継ぎに戻る |
| K7 | カテゴリを追加・名前変更・削除する | Tab、矢印、文字入力、Enter、Esc | 各操作が完了し、フォーカスが元の操作要素に戻る |
| K8 | CSV を書き出す | Tab、矢印、Enter | ファイルが保存される |
| K9 | CSV を読み込み、プレビューで確定・キャンセルする | Tab、Enter（ファイル選択）、Tab、Enter、Esc | 確定で追加、Esc で何も追加されず「ファイルを選ぶ」に戻る |
| K10 | 入力エラーから直す | Enter、文字入力、Enter | 最初のエラー項目にフォーカスが移り、直すと保存できる |

- 各シナリオはマウスを使わずに完了できること。
- ファイル選択ダイアログ（OS の画面）の中の操作は自動テストの対象外とし、テストではファイル入力にテスト用の架空 CSV を直接与える。OS のダイアログを開くまで（Enter/Space で開けること）は確かめる。
