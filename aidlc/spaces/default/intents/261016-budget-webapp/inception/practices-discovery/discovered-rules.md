# 発見されたハードルール

> 人間の依頼文に明示され、ヒアリング Q7（A: そのまま記録）で恒久的な制約として確認された 6 件です。

## Mandated

- ALWAYS アプリケーション、テスト、サンプル、CSV の入出力例に使うデータは架空（合成）データのみとする。
- ALWAYS アプリケーションは TypeScript で実装する。
- ALWAYS 各ステージの承認・レビュー・テストを省略せずに実施し、承認が必要な箇所では人間の回答を待ってから先へ進む。

## Forbidden

- NEVER 実在の銀行口座・金融サービスと連携する機能を実装しない。
- NEVER アプリケーションのデータを外部のサーバーやサービスへ送信しない。
- NEVER 実在の個人・口座・取引に由来するデータをアプリケーション、テスト、リポジトリに含めない。
