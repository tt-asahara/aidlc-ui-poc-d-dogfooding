# 外部依存の一覧

- Bolt（ボルト）とは、作業の一部を1回で設計から実装・テストまで通し、動くものを仕上げる単位である。
- このアプリは架空データだけを使い、実口座連携・外部送信をしない（project.md）。外部の API、データの提供待ち、他チームの引き渡し、承認の待ち時間はない。
- 唯一の外部依存は、開発時の道具（無償の公開パッケージ）の取得である（Q3 = A）。これはアプリのデータの送信ではない。

| 依存 | 持ち主 | 待ち時間 | 使う Bolt | 遅れたとき・使えないときの対応 |
|------|--------|----------|-----------|--------------------------------|
| npm 公開レジストリからの無償パッケージの取得（TypeScript、React、Vite、テストの道具、Lint・整形の道具、テスト用の IndexedDB 実装など。具体的な選定は各 Unit の設計で行う） | パッケージの公開者（第三者） | 取得時の数分程度 | B1（最初の環境構築）、以降は必要に応じて | 取得できない場合は作業を止めて利用者に相談する。有償のサービス・認証の変更・追加購入はしない |
| ブラウザ組み込みの IndexedDB・ファイル API | 利用者のブラウザ | なし | B2、B5、B7 | 使えない環境では「この環境ではデータを保存できません」と表示する（FR8.4） |

- パッケージのバージョンはロックファイルで固定する（NFR9）。
- アプリの実行時には、配信元以外へのネットワーク要求を行わない（NFR1）。
