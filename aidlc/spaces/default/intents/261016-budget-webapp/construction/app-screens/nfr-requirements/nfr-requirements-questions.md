# NFR Requirements（app-screens）— 質問

この Unit の非機能要件で、新たに利用者の判断が必要な点はありません。

- 依存の追加は Vite（ビルドと開発サーバー）と、そのための最小限の拡張だけで、承認済みの方針（無償の公開パッケージのみ、有償サービス・認証変更・追加購入なし）の範囲に入る。バージョンは追加のときに正確に固定し、ロックファイルに記録する。
- 性能（NFR3）の 500ms と 2 秒は、本物の IndexedDB と Chrome でだけ確かめられる。その確認は Build and Test で行う（jsdom では測らない）。
- 対応ブラウザ（NFR7）の確認は、Chrome を主に Build and Test で行う。Edge・Firefox・Safari は同じ検査を手で行い、結果を記録する（自動化はしない）。
- U2 で残した実ブラウザの確認 B1〜B5（フォーカス、Esc、背後の操作不可、コントラスト）は、この Unit の Build and Test の項目として引き継ぐ。
